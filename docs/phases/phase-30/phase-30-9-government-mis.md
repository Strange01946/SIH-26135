# Phase 30.9 government MIS coverage

The dashboard at `/analytics` uses the Q01–Q11 numbering in `database/phase-18-dashboard-analytical-queries.sql`. The reporting period is the financial year of enrollment. Other common filters are scheme, sector, state, district, and recorded gender. Geography uses the trainee’s location. When a district is selected, its parent state is selected with it. Q07–Q11 link to the filtered enrollment cohort when a filter is applied and include unlinked records in the all-time, unfiltered nationwide view where the query grain allows it.

**Nationwide access** requires `analytics.read` and the existing server-side nationwide scope check. That check verifies an eligible super admin, government admin, or national analyst against the account’s recorded assignments. The state endpoint also enforces its existing state scope. The frontend waits for the complete set of endpoint responses for the selected filters before rendering an updated dashboard.

The Social Category control is disabled because the Phase 27 schema has no authoritative category field. The filter API identifies this as unsupported. The scheme catalog records an administering organization and budget, with no funding split. The comparison names each administrative group explicitly.

The dashboard displays published values and uses the API’s explicit suppression state or nullable measure contract. A null wage can also indicate a lack of comparable salary observations. Visuals omit hidden values from bar dimensions and labels. The funnel withholds stages when adjacent values would disclose a small drop-off. The page makes no client-side subtotals, residuals, or exports.

The tests in `frontend/src/__tests__/analytics/misDashboard.test.tsx` check the shared filters across all endpoints, omission of suppressed geometry, and sorting of released values. Backend coverage includes `AnalyticsMultiDimensionalFilteringTest`, `EconomicOutcomeDashboardIntegrationTest`, `InstitutionalAnalyticsIntegrationTest`, `DashboardTenancyAndRoleAuthorizationTest`, and `AnalyticsStatisticalDisclosureControlTest`. The live checks in the table used Spring Boot, Vite, and Chromium against `SIH26135_TEST`, with both publishable cohorts and cohorts below the disclosure threshold.

The locally bundled map adapts the 36-area India ADM1 dataset collected by DataMeet India and the Election Commission of India. It uses a simplified local projection for interactive state selection.
