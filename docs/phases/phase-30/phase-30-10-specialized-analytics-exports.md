## Exports

The export dialog supports CSV and JSON. DSDP requires district scope, QPR requires nationwide scope, and the provider scorecard uses the existing provider/state scope rules. Each statutory report keeps its backend-defined columns. The candidate report offers selectable columns from `/api/v1/analytics/export/candidates/columns` and streams from `/api/v1/analytics/export/candidates/{csv|json}`.

The candidate report requires `analytics.read`, `trainee.read`, verified nationwide scope, and each candidate’s latest active `ANALYTICS` consent. It projects one row from the latest enrollment per candidate and accepts filters that preserve the complete privacy grouping. The grouping includes financial year, scheme, sector, state, district, gender, and recorded outcome stage regardless of the selected projection. Groups below k=5 are excluded before writing. Rows carry no identifiers or individual wage values. The existing export quotas and maximum row ceiling are applied.

The browser sends the bearer token in the request header. It pipes response chunks to a user-selected file when the save picker is available, or writes to the origin-private filesystem and offers the staged file to browser downloads. A changed or compressed/unknown length uses bytes received, with a percentage indicator only for a reliable uncompressed total. [File System API](https://developer.mozilla.org/en-US/docs/Web/API/File_System_API) · [MySQL Connector/J streaming](https://dev.mysql.com/doc/connector-j/en/connector-j-reference-implementation-notes.html).

The live Chromium run used Spring Boot, Vite, and the isolated `SIH26135_TEST` database. It verified all eleven formal panels, recorded wage and dropout data, the DQI gauge against the actual scorecard API, and all three statutory attachment routes. The disk-backed browser download produced 10,003 rows in each candidate file. The CSV was 190,031 bytes and the JSON was 470,342 bytes. Both contained the selected two columns. Three candidates in a sparse group, a candidate with revoked consent, and a candidate without consent were excluded. The temporary data and files were removed.

`frontend/src/__tests__/analytics/misExport.test.ts` covers column parameters, measured and unmeasured byte progress, and aborting on a truncated response. The backend regression breadth includes `AnalyticsExportTest`, `AnalyticsStatisticalDisclosureControlTest`, `RetentionAttritionDashboardIntegrationTest`, `SkillGapDashboardIntegrationTest`, `DataIntegrityDashboardIntegrationTest`, and `OperationalDashboardIntegrationTest`.
